# Automotive AI Solutions — primary learning track

Start here for customer-facing cloud and AI solution architecture. Learn by delivering a bounded automotive PoC and explaining its architecture, evidence and tradeoffs.

Order: **018 -> 019 -> 020 -> 021 -> 022 -> 023**. Finish a useful local slice before adding infrastructure. No foundation-course completion is required. Automotive enterprise AI (019–021) builds the solution-delivery skills; data loops and simulation (022–023) connect those skills to Physical AI.

Read the [roadmap](../../docs/solution-first-roadmap.md), [role alignment](../../docs/role-alignment.md), and [templates](../../templates/solution/README.md). All customer scenarios are fictional; no cloud resources, external APIs or vehicle systems have been provisioned.
